========================================
UI / HUD PROMPTS (2D OVERLAY)
========================================

Improve the Hotbar (src/components/Hotbar.js) and biome menu in App.jsx: clearer labels, ball icons, catch count, and ordinary-left counter. Keep styles in App.css with unique class names; avoid inline styles.

Make the HUD fully responsive on mobile and tablet: biome list, throw power indicator, and instructions readable without covering the canvas.

Add a polished LoadingOverlay for biome transitions: progress text, fade in/out, and ensure it never sticks (fix race between preloadBiome and handleBiomeReady).

Add a title / welcome screen before entering the Canvas, with a "Play" button and control summary.

Add pause menu (Escape): resume, switch biome, reset catch count, controls reference.

Apply a cohesive dark UI theme to all overlay panels with high contrast over the 3D scene.

========================================
3D SCENE & R3F PROMPTS
========================================

Refactor GameScene.js into smaller modules: creature spawning, projectile/catch logic, companion state, and weather — without changing gameplay behavior. Learn, understand, and analyze deeply, then break tasks into smaller tasks.

Add a new R3F component following patterns in AnimatedModel.js and ModelErrorBoundary.js: Suspense, error fallback to VoxelFallback, and manifest-driven scale/rotation.

Improve ThirdPersonCamera.js: smoother follow, collision-aware zoom optional, and stable behavior during pointer lock.

Optimize VoxelWorld.js instanced mesh updates when biome cache changes; avoid full remount when possible.

Extend Atmosphere.js and OceanHorizon.js for biome-specific sky color, fog, and sun position (use SUN_POSITION from Atmosphere.js).

========================================
GAMEPLAY PROMPTS
========================================

Support multiple alpha variants: alpha folder + random selection in getAlphaCreatureAsset().

Improve WildCreature.js AI: wander within walkable tiles (isWalkablePosition), flee from player, or idle animations.

Implement companion recall/send (E key) with CompanionRecallEffect; align companion height with COMPANION_HEIGHT in world.js.

Add new ball type in src/game/balls.js: wire key binding in App.jsx and visual in Projectile.js / Hotbar.js.

Enhance useKeyboardControls.js or centralize input in a single hook used by Player and App.
