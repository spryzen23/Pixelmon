# Single Battle Rules

A Single Battle is a classic 1v1 battle format where each trainer sends out one Pokémon at a time.

## Turn Order Sequence

1. **Check Move Priority Brackets**: Priority always wins, regardless of Speed. The game first groups both Pokémon by the priority bracket of the move they selected. A higher number always goes first. For example, Protect is +4, Fake Out is +3, standard attacks are 0, and Trick Room is -7.
2. **Compare Speed Stats**: If both Pokémon use moves in the same priority bracket, the game compares their current Speed stats. The higher Speed goes first. If Trick Room is active, this step is reversed.
3. **Resolve Speed Ties**: If Pokémon are in the same priority bracket and have the exact same Speed stat, the game flips a virtual coin to determine who goes first (Speed Tie).
4. **Apply Dynamic Recalculation**: If a Pokémon's Speed changes mid-turn, the turn order instantly recalculates for the remaining actions.

## Modes
- **3v3**: Each trainer brings a team of 3 Pokémon.
- **6v6**: Each trainer brings a team of 6 Pokémon.
