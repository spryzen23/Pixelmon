# ========================================
# 1. PROJECT OVERVIEW
# ========================================
#
# Pixelmon (package name: pixelmon) is a browser-based voxel creature-catching prototype.
#
# Stack:
#   - React 19 + Create React App (react-scripts 5)
#   - Three.js + @react-three/fiber + @react-three/drei
#   - InstancedMesh terrain, GLB models from public/assets
#   - Jest + React Testing Library (unit tests)
#
# Game design (current):
#   - 6 finite biomes (WORLD_PATHS in src/game/world.js)
#   - One active biome at a time; 3x3 chunk map per biome
#   - Ordinary creatures + alpha spawn after all ordinary caught
#   - Third-person movement, pointer lock, projectile catching
#   - Weather: sandstorm (desert), snowstorm (snow biomes)
#
# Dev server: http://localhost:3000 (default CRA port)
#

# 4. CODEBASE.BAT (FULL PIPELINE)
# ========================================
#
# Windows batch launcher. Copies itself to %TEMP% so edits mid-run do not break execution.
#
# Default pipeline (steps 0–6), then optional step 7 (npm start):
codebase.bat
#
# Environment flags (set before running):
#
# SKIP_ASSET_INVENTORY=1     Skip GLB inventory under public\assets
# SKIP_CLEAN=1               Keep node_modules; only remove build\ and coverage\
# SKIP_PRETTIER=1            Skip Prettier
# RUN_PRETTIER=1             Run Prettier even without .prettierrc
# SKIP_ESLINT=1              Skip ESLint
# RUN_TEST_COVERAGE=1        Run Jest with --coverage (step 5b)
# AUTO_START_DEV=1           Start npm start after checks without prompting
# AUTO_SKIP_DEV=1            Never prompt for dev server
#
# Examples:
set SKIP_CLEAN=1&& codebase.bat
set AUTO_START_DEV=1&& codebase.bat
set RUN_TEST_COVERAGE=1&& codebase.bat
#
# Pipeline steps:
#   [0] Asset inventory — counts public\assets\*.glb, warns if core GLBs missing
#   [1] Clean + npm install (unless SKIP_CLEAN=1)
#   [2] TypeScript — skipped (JavaScript CRA project)
#   [3] Prettier check/write on src and public
#   [4] ESLint on src (with --fix retry)
#   [5] Jest tests
#   [5b] Coverage (optional)
#   [6] npm run build
#   [7] npm start (optional)
#
# Capture full log to file:
codebase.bat > error.txt 2>&1
#

# 5. ASSET COMMANDS
# ========================================
#
# Count biome GLB models (PowerShell):
powershell -NoProfile -Command "(Get-ChildItem -Path 'public\assets' -Filter '*.glb' -Recurse).Count"
#
# List all GLB paths:
dir /s /b public\assets\*.glb
#
# Legacy poke_glb folder (if present):
dir /s /b public\poke_glb\*.glb
#
# Verify core assets exist:
if not exist "public\assets\player.glb" echo MISSING player.glb
if not exist "public\assets\companion.glb" echo MISSING companion.glb
if not exist "public\assets\wild_creature.glb" echo MISSING wild_creature.glb
#
# Add a new ordinary creature:
#   1. Copy GLB to: public/assets/<Biome Name>/ordinary/creature_XX.glb
#   2. Register in CREATURE_ASSET_MANIFEST in src/game/world.js
#   3. Folder name must match WORLD_PATHS[].name exactly (spaces allowed; URLs encoded in code)
#
# Add a new biome:
#   1. Create folder: public/assets/<New Biome Name>/ordinary/ and alpha.glb
#   2. Add entry to WORLD_PATHS and CREATURE_ASSET_MANIFEST in src/game/world.js
#   3. Wire biome button in src/App.jsx biome menu
#   4. Add weather/atmosphere rules in GameScene if needed
#

# ========================================
# 12. TROUBLESHOOTING
# ========================================
#
# npm install fails:
#   - Use Node 18+ LTS
#   - Delete node_modules and package-lock.json, then npm install again
#
# npm run build fails:
#   - Run npx eslint src and fix errors
#   - Check for case-sensitive import paths (Linux CI vs Windows dev)
#
# Black screen / WebGL context lost:
#   - Update GPU drivers; try another browser
#   - Reduce canvas pixel ratio in App.jsx if added
#
# Models invisible or huge:
#   - Fix CREATURE_ASSET_MANIFEST scale/rotation
#   - Confirm file path matches biome folder name (spaces → encoded URLs in world.js)
#
# Biome switch infinite loading:
#   - Check handleBiomeReady / preloadBiome in App.jsx and world.js
#   - clearAllBiomeCaches on switch
#
# Pointer lock not working:
#   - User gesture required; click canvas first
#   - See SafePointerLockControls.js
#
# Tests fail in CI but pass locally:
#   - set CI=true before npm test
#   - Avoid timing-dependent tests without mocks
#
# codebase.bat BOM error on first line:
#   - Save codebase.bat as UTF-8 without BOM
